10. 定理与提示卡片

最小势能原理

在所有满足位移边界条件的许可位移场中，真实位移场使系统总势能取驻值。

小变形假定

位移梯度远小于 1，应变张量采用小应变定义 $\varepsilon_{ij} = \frac{1}{2}(u_{i,j} + u_{j,i})$。

网格敏感性

损伤模型存在网格依赖性，需引入正则化方法。

11. 代码块（含 LaTeX 源码，不应被公式引擎改写）

PYTHON
import numpy as np

def assemble_stiffness(coords, E, nu):
    """组装平面单元刚度矩阵"""
    # 材料矩阵 D
    D = E / (1 - nu**2) * np.array([[1, nu, 0],
                                    [nu, 1, 0],
                                    [0, 0, (1 - nu) / 2]])
    return D
